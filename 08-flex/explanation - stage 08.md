### Карта компонування: Зв'язок HTML-структури та CSS-правил

**1. Основа сторінки (Body та Main)**
* **Селектори:** `body`, `main`
* **Ключові стилі:** `main { max-width: 960px; margin: 0 auto; }`
* **Технічне пояснення:** Застосовано стандартний потік документа (Normal Flow). Елемент `<main>` центрується по горизонталі за допомогою автоматичних зовнішніх відступів (`margin: 0 auto`) в межах заданої максимальної ширини.

**2. Шапка (Header)**
* **Селектори:** `header`, `.header-content`
* **Ключові стилі:** `header { display: flex; align-items: flex-start; gap: var(--space-2xl); }`
  `.header-content { flex: 1; min-width: 0; }`
* **Технічне пояснення:** Використано Flexbox. Властивість `align-items: flex-start` вирівнює дочірні елементи (`figure` та `.header-content`) по верхньому краю. Властивість `flex: 1` для `.header-content` змушує цей блок зайняти весь доступний простір по головній осі після рендерингу зображення.

**3. Меню навігації (Nav)**
* **Селектор:** `nav`
* **Ключові стилі:** `nav { display: flex; align-items: center; }`
* **Технічне пояснення:** Flexbox застосовано для формування однорядкового розташування елементів `<a>`. Властивість `align-items: center` забезпечує їх вертикальне центрування відносно висоти контейнера `nav`.

**4. Досвід роботи (Заголовки статей)**
* **Селектор:** `article > header`
* **Ключові стилі:** `article > header { display: flex; align-items: center; gap: var(--space-sm); }`
* **Технічне пояснення:** Використано Flexbox для горизонтального позиціонування зображення (`img`) та текстового блоку (`.article-meta`). Відступ між ними контролюється властивістю `gap`.

**5. Портфоліо (Сітка карток)**
* **Селектори:** `.portfolio-grid`, `.portfolio-grid article`
* **Ключові стилі:** `.portfolio-grid { display: flex; flex-wrap: wrap; gap: var(--space-md); }`
  `.portfolio-grid article { flex: 0 0 calc(50% - var(--space-sm)); }`
* **Технічне пояснення:** Реалізація сітки на базі Flexbox. Контейнер `.portfolio-grid` дозволяє перенесення елементів (`flex-wrap: wrap`). Кожен елемент `article` має жорстко задану ширину через `flex-basis: calc(50% - 8px)`, що формує структуру з двох колонок.

**6. Портфоліо (Внутрішня структура картки)**
* **Селектори:** `.portfolio-grid article`, `.card-body`
* **Ключові стилі:** `.portfolio-grid article { display: flex; flex-direction: column; }`
  `.card-body { flex: 1; display: flex; flex-direction: column; justify-content: space-between; }`
* **Технічне пояснення:** Контейнер картки налаштовано як Flex-стовпець. Блок `.card-body` отримує `flex: 1`, що дозволяє йому розширюватися на всю доступну висоту. Вкладений Flexbox у `.card-body` з `justify-content: space-between` фіксує блок посилань (`.card-links`) у нижній частині картки.

**7. Навички (Бейджики технологій)**
* **Селектор:** `.badges-row`
* **Ключові стилі:** `.badges-row { display: flex; flex-wrap: wrap; gap: var(--space-xs); }`
* **Технічне пояснення:** Застосовано Flexbox з дозволом на перенесення рядків. Відступи між елементами `.skill-badge` реалізовані виключно через властивість `gap` батьківського контейнера, без використання марджинів на самих елементах.

**8. Мови (Список описів)**
* **Селектор:** `dl`
* **Ключові стилі:** `dl { display: grid; grid-template-columns: auto 1fr; gap: var(--space-sm) var(--space-md); }`
* **Технічне пояснення:** Використано CSS Grid. Властивість `grid-template-columns: auto 1fr` формує двовимірну сітку. Перша колонка (`dt`) автоматично підлаштовується під ширину контенту, друга (`dd`) займає залишок доступної ширини контейнера.

**9. Підвал (Footer Контакти)**
* **Селектори:** `.footer-contacts`, `.contact-item`
* **Ключові стилі:** `.footer-contacts { display: flex; flex-wrap: wrap; }`
  `.contact-item { flex: 0 0 50%; display: flex; align-items: center; }`
* **Технічне пояснення:** Flexbox застосовано для поділу списку на дві колонки. Контейнер дозволяє перенесення (`flex-wrap: wrap`), а кожен дочірній елемент `.contact-item` отримує фіксовану ширину 50% через `flex-basis`. Внутрішня структура `.contact-item` також є Flex-контейнером для вирівнювання мітки та посилання по одній осі.
