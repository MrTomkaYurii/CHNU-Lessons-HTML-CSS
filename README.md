# 🌐 CHNU-Lessons-HTML-CSS

Навчально-практичні матеріали та приклади з курсу **«Основи веб-розробки: HTML5 та CSS3»** для студентів кафедри комп'ютерних наук Чернівецького національного університету імені Юрія Федьковича.

---

## 📚 Структура практичних занять

| Тема | Опис |
| :--- | :--- |
| **01-скелет** | Базова структура HTML-документа: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`, мета-теги та кодування UTF-8 |
| **02-текст-заголовки** | Ієрархія заголовків `<h1>`–`<h6>`, параграфи `<p>`, форматування тексту, виділення `<strong>`, `<em>` |
| **03-структура-семантика** | Сучасні семантичні теги HTML5: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>` |
| **04-списки-посилання** | Невпорядковані (`<ul>`) та впорядковані (`<ol>`) списки, гіперпосилання `<a>`, абсолютні та відносні шляхи |
| **05-зображення-медіа** | Робота з графікою `<img>`, атрибути `src`, `alt`, розміри та адаптивне вбудовування медіа |
| **06-перший-css** | Вступ до каскадних таблиць стилів (CSS): синтаксис правил, селектори тегів/класів/ідентифікаторів, підключення стилів |
| **07-блочна-модель** | CSS Box Model: `content`, `padding`, `border`, `margin`, властивість `box-sizing: border-box` |
| **08-flex** | Сучасна верстка за допомогою Flexbox: `display: flex`, осі, вирівнювання `justify-content`, `align-items`, адаптивність |
| **09-багатофайловість** | Структура багатосторінкового сайту, організація асетів, відносні посилання та навігація |

---
